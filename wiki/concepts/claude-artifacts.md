# Claude Artifacts

A standalone output from [[claude]] (a doc, deck, design, dashboard or prototype) that opens
in its own window next to the chat. In the course's words: "conversation = where you make it,
artifacts tab = where it lives".

## Explanation

- **Where they live:** on paid plans, in the **Artifacts tab**, independent of the chat. On
  Free they stay with the chat. You can force one with "create this as an artifact"
  ([[claude-101-course-notes]]).
- **Beta types (paid)** ([[claude-101-course-notes]]):
  - **Claude Design:** landing pages, mockups and prototypes on a drag/resize canvas; can use
    your design system.
  - **Claude Slides:** decks from notes or reports; edit and present inside Claude; export
    to pptx/pdf.
  - **Claude Docs:** living, multiplayer documents in which Claude explains its choices in
    comments. Charts from connected tools are **snapshots**; ask Claude to refresh them.
    Export to Google Docs or docx.
  - You can convert between types ("turn this doc into a deck"). On by default for
    Pro/Max/Team; off on Enterprise until an admin enables it.
- **All plans, including Free:** dashboards, trackers, flowcharts, interactive pages, code
  ([[claude-101-course-notes]]).
- **Artifact ≠ file creation.** File creation produces downloadable Word, Excel, PowerPoint or
  PDF files via [[claude-skills]] ([[claude-101-course-notes]]).
- **Editing**, in any mix: edit directly; comment on the exact passage (@claude in a Docs
  comment); or ask in chat. Editing is desktop/web only; mobile is view-only
  ([[claude-101-course-notes]]).
- **Sharing:** private by default, with view/comment/edit permissions; viewers need a Claude
  account. Pro/Max can share by link or publish a design or deck publicly (the chat stays
  private). Team/Enterprise share inside the org only unless the owner enables external
  sharing ([[claude-101-course-notes]]).

# Claude Cowork

The [[claude]] desktop tab for **handing off** multi-step work. It plans, works across tools
and files, and saves finished files where you need them, instead of answering one turn at a
time.

## What we know

- **When to use it:** multi-step tasks, work across many tools, finished files saved to a
  location, and scheduled or background jobs ([[claude-101-course-notes]]).
- **How it behaves:** it shows a plan first, may ask clarifying questions, lets you watch and
  steer, and asks before risky actions such as sending email ([[claude-101-course-notes]]).
- **Features** ([[claude-101-course-notes]]):
  - Local folder access. It reads files and **saves back** into the folder, whereas chat only
    offers downloads.
  - **Scheduled tasks** run remotely, so they work while the laptop sleeps. Tasks that need
    local files require the app to be open.
  - Subagents that split big jobs into parallel workers.
  - Projects for tasks, like [[claude-projects]] are for chat.
  - Browser use via [[claude-in-chrome]]. Computer use (research preview, Pro/Max) clicks and
    types where no connector exists, and asks per app.
  - **Plugins:** role bundles of [[claude-skills]], [[claude-connectors]] and agents (sales,
    finance, legal…), under Customize → Plugins.
- **Examples:** "what did we decide on pricing last quarter across notes/Slack/email → update
  the Q3 deck"; summarise 50+ docs into a memo; a Monday-morning briefing
  ([[claude-101-course-notes]]).
- **Plans:** Pro, Max, Team, Enterprise ([[claude-101-course-notes]]).

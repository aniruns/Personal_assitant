## 1. what is claude

- not "just a chatbot" -> pitched as a **thinking partner**
- trained w/ **Constitutional AI** = principles to keep it safe / not toxic / not help w/ illegal stuff, aligned to human values
- "steerable" = you can tell it tone, personality, behaviour and it actually listens
- good at: writing, research+analysis, coding (they say this is a big strength), reasoning/maths, learning
  - **Thinking** = it can stop and reason step by step before answering
  - **Learning mode** = guides you to the answer instead of just handing it over (good for actually learning)
- context window = 200K+ tokens (~500 pgs). **1M** on paid plans w/ supported models
- access: web / desktop / mobile, ALL plans. chats, projects, memory sync across devices
- other surfaces: Claude Code, Claude Tag (slack), Claude Design, Claude for M365 -> more in lesson 12

## 2. first conversation

talk to it like a **coworker**. natural, concise. no magic words needed

**prompt framework (3 parts):**

1. **set the stage** – who am i, what's the goal, any context
2. **define the task** – what do i want it to DO (write / analyse / build…)
3. **specify rules** – tone, format, length, examples

their eg: marketing lead @ indie streaming startup -> research the market for a series A deck -> w/ citations, 5 pg report, exec summary etc. hits all 3

- this is from the **4D AI Fluency framework** (Dakan + Feller). see lesson 3

**context:**

- uploads: pdf, docx, csv, txt, png/jpg. it reads charts/images inside pdfs too
- settings > account > "instructions for claude" = applies to every chat

**iterating** (this is the main point really):

- follow-ups ("expand pt 2", "shorter pls")
- feedback ("too formal")
- redirect ("no i meant X")
- worst case = new chat, fresh context
- ✏️ pencil icon = edit your msg & resend

**personalisation:**

- **memory** – remembers role/prefs/decisions. can edit/delete in settings
- **skills** – reusable instruction packs (lesson 7)

## 3. getting better results (~12 min)

common problems → fixes:

| problem             | fix                                                                              |
| ------------------- | -------------------------------------------------------------------------------- |
| too generic         | add context: who it's for, constraints, history                                  |
| wrong length        | just say it. "2 paras" / "<100 words"                                            |
| ignored format      | SHOW an example, don't just describe it                                          |
| confident but wrong | verify the important stuff, ask for sources/confidence level, turn on web search |
| wrong tone          | describe it in plain words + give a sample                                       |

**iteration mindset**

- first draft = starting point, not the final thing
- specific feedback > vague ("cut first 2 paras, end on an action" > "shorter")
- if it's gone off the rails -> just start over

**AI fluency – 4Ds**

- **Delegation** – what should a human do vs the AI
- **Description** – communicating clearly (= the prompt framework)
- **Discernment** – judging the output critically
- **Diligence** – responsible/ethical use, owning the result
- free AI Fluency course if I want more

**evals** (simple version, no tooling needed):

1. grab 5–10 examples of a task i already do
2. write prompts that should produce something similar
3. compare. key info there? tone ok? what's missing?
4. tweak prompts / add examples / decide where a human review is a must

- eg: take a dataset i already analysed by hand, have claude do it, compare. *maybe gets the numbers right but misses the bigger patterns*

## 4. desktop app — 3 "shapes" of work (~11 min)

the whole lesson is basically: **figure out which kind of work it is first, then the tab is obvious**

**a) turn-by-turn → Chat**

- use when the answer changes what you ask next / you want to stay in the loop / it's quick
- desktop extras: double-tap **Option** (mac) = quick entry window that floats on top, screenshots + window sharing, dictation, desktop connectors
- egs: screenshot an unfamiliar dashboard and ask what it means; talk through a deck outline by voice between meetings

**b) hand it off → Cowork**

- multi-step stuff, finished files saved where you need them, work across many tools, scheduled/background
- shows you a plan first, can ask clarifying Qs, you can watch & steer. asks before risky stuff (sending email etc)
- features:
  - local folder access (reads + **saves back** into the folder; chat only gives you downloads)
  - **scheduled tasks** – run remotely so it works even if laptop is asleep (unless it needs local files → then app has to be open)
  - subagents – splits big jobs into parallel workers
  - projects (like chat projects but for tasks)
  - browser use via claude in chrome
  - computer use (research preview, pro/max) – clicks/types for you when there's no connector, asks per app
  - **plugins** – bundles of skills+connectors+agents per role (sales, finance, legal…). customize → plugins
- egs: "what did we decide on pricing last qtr across notes/slack/email → update the Q3 deck"; summarise 50+ docs into a memo; a monday morning briefing
- pro / max / team / enterprise

**c) build software → Code tab**

- claude code inside the app. diffs, terminal, git
- local (a folder on your machine) or cloud (github repo, keeps running after you close the app)
- modes: manually approve / accept edits / plan
- non-devs can ignore → "Claude Code in Action" course

## 5. projects (~14 min)

= self-contained workspace: own chats, knowledge base, instructions, memory

use when: reference docs you keep re-uploading, same rules every time, team needs the same context

**setup**

1. claude.ai/projects → + New Project → name + description (claude DOESN'T see the description, it's for humans) → private or shared w/ the org
2. **instructions** – context, process ("first outline, then draft"), tone, must-haves ("always end w/ a CTA")
   - can automate: "when i upload a transcript → summarise using this template"
3. **knowledge** – + button, pdf/docx/csv/txt/html, google drive
   - **name files properly!!** "Q4-2024-Brand-Guidelines.pdf" not "document1.pdf". claude uses file names to find stuff

**big knowledge bases** -> auto switches to **RAG** (searches & pulls only the relevant bits) near the context limit. ~**10x** capacity, you get an indicator

**sharing (team/ent):** can view / can edit / owner. share w/ people or "everyone at org"

ideas: product launch hub, research support, client account hub, event planning, JD generator

tips: start narrow, keep docs up to date, clear instructions, mention docs by name in questions

## 6. artifacts (~12 min)

artifact = a standalone output (doc / deck / design / dashboard / prototype) in its own window next to the chat

- paid plans → saved in the **Artifacts tab**, not tied to the chat. free → stays with the chat
- "conversation = where you make it, artifacts tab = where it lives"
- can force it: "create this as an artifact"

**the 3 big ones (beta, paid):**

- **Claude Design** – landing pages, mockups, prototypes. can use your design system. drag/resize on a canvas
- **Claude Slides** – decks from notes/reports. edit slides, present inside claude, export pptx/pdf
- **Claude Docs** – living docs, multiplayer editing, claude explains its choices in comments. charts from connected tools = **snapshot**, ask it to refresh. export to google docs / docx
- can convert between them: "turn this doc into a deck"
- defaults: on for pro/max/team; enterprise = off until admin turns on (org settings > artifacts)

**every plan incl. free:** dashboards, trackers, flowcharts, interactive pages, code

artifact ≠ file creation (file creation = downloadable word/excel/ppt/pdf)

**editing** – 3 ways, mix freely:

1. edit directly
2. comment on the exact bit (in docs, @claude in a comment)
3. just ask in chat
   (editing/commenting = desktop/web only. mobile = view)

**sharing** – private by default. view/comment/edit (docs = view/edit). viewers need a claude acct

- pro/max: private or anyone w/ link, can publish design/deck publicly (the chat stays private)
- team/ent: inside org only unless owner turns on external sharing
- free: copy / download / publish
- exports: deck → pptx/pdf, design → pptx/pdf/html, doc → gdocs/docx

tips: **ask for the deliverable, not the content** ("make a 1-pg doc for leadership" > "summarise Q3"); be specific; say who it's for; build at the END of a convo when claude already gets it

## 7. skills (~16 min)

skills = folders of instructions + scripts + resources, loaded when needed. "expertise packages"

- **anthropic skills** – excel / word / ppt / pdf creation. automatic
- **custom skills** – yours/org's. eg brand guidelines, meeting note format, variance analysis

**enable:** settings > capabilities > "code execution & file creation" ON > toggle skills

- enterprise → owner has to enable first. team → on by default

using: you don't call them, claude picks. shows in its chain of thought. output = file download / google drive

- upload a file in chat = it makes a **new version**, doesn't edit your original
- may need "allow limited network access"

security: runs code → only install from trusted sources, read external skills before using. custom skills are private to your account

**making one:** just tell claude "i want a skill for X" → it interviews you → upload templates/examples → save. see/edit them under **Customize** in the sidebar. iterate by asking it to edit

**skills vs projects** ⭐

- projects = **knowledge** (the what)
- skills = **process** (the how)
- they stack: a "call prep" skill can pull from customer profiles sitting in a project

## 8. connectors (~16 min)

connectors = claude gets access to your actual tools → read AND act (search, create, update…)

- powered by **MCP** (model context protocol) — "USB-C for AI", open standard
- 2 types:
  - **web** – gdrive, notion, slack, asana, gmail, linear, stripe…
  - **desktop extensions** – local files, browser control, native apps (figma). desktop app only → settings > extensions
- directory: **claude.ai/directory**, or + > connectors in chat
  - listed by connector not app → eg jira/confluence = look for **Atlassian Rovo**
  - nothing for your tool? → custom connector
- setup: connect → log in → approve perms → test ("can you access my X?")

egs: "highest priority tasks this week" (asana/jira), "find the vendor contract thread" (gmail), "what does the style guide say about contractions" (notion), "revenue trend last qtr" (stripe)

security:

- scoped perms, can toggle each one
- **claude sees only what YOU can see** (connecting my email ≠ CEO's inbox)
- revoke anytime. custom connectors = trusted sources only

## 9. enterprise search (~17 min) — team/enterprise only

- "**Ask {Org}**" in the sidebar = basically a pre-built project with all the company knowledge already hooked up
- built for info gathering, w/ custom instructions from anthropic
- searches across sharepoint / slack / gmail / drive etc → one answer **with citations**
- egs: "what happened yesterday while i was out", remote work policy, expense process, why customers pick competitors, who to talk to about billing, decisions from leadership mtgs

setup:

- **admin/owner:** ask your org → set up → MUST connect a docs source (drive/sharepoint) + a chat source (slack/teams), email optional → name it → finish
- **users:** click it → guided onboarding → log into each service. more connectors = better results

safe? → only shows what you already have access to, chats private, data isn't indexed/stored separately

## 10. research (~12 min)

= agentic, multi-step investigation. lots of searches that build on each other → report w/ citations

- takes **minutes**, not seconds (can hit 100s of sources)
- uses Thinking to plan first

flow: plan → many searches → synthesise (web + gmail/cal/drive etc) → cite everything

**when to use what** ⭐

- **research** → big reports, comparisons, competitor/vendor stuff, things that'd take hours manually
- **web search** → a quick fact, 1–2 sources, speed matters
- **thinking** → pure reasoning (maths, debugging, logic), no outside info needed
- **enterprise search** → internal company stuff

how: + menu → Research (web search needs to be on too)

prompt tips: be specific about the goal, give it the structure/sections you want, add constraints (budget/time/location), ask claude to help write the research prompt itself

w/ integrations: "summarise project X across email+slack then research best practices", "check my calendar next wk + research each company i'm meeting"

## 12. other ways to use claude (~17 min)

- **Claude Code** – agentic coding. terminal / IDE / browser / slack. build features in plain english, debug, understand a codebase, lint/merge conflicts/release notes
- **Claude Tag** – claude in slack, tag it in a thread. summarise threads, meeting prep, onboarding via channel history, **kick off a claude code session from a bug thread**
- **Claude Design** – brief/sketch/screenshot → working prototype. compare variations, uses your design system. also at claude.ai/design. beta, paid
- **Claude for M365** (sidebars)
  - excel: explain formulas across tabs, change assumptions w/o breaking deps, trace #REF!/#VALUE!/circular refs, pivots + charts
  - ppt: notes → deck, tighten copy + speaker notes, restructure, keeps template/brand
  - word: draft in the team template, revise tone, work through tracked changes/comments, grounded in connected sources
  - outlook (beta, separate install): triage, replies w/ thread + calendar context, summarise long chains
- **Claude in Chrome** – browser sidebar, can see the page + act. summarise pages, email, forms, multi-step workflows, internal tools/CRMs
  - GA. on by default for pro/max/team, enterprise needs admin. NOT on free
  - low-risk tasks on trusted sites. asks before purchases/personal data. financial + adult sites blocked by default

**cheat sheet**

- claude.ai → general stuff
- code → dev
- cowork → multi-step hand-offs
- tag → slack/team
- design → UI prototypes
- M365 → editing inside office apps
- chrome → web + browser automation
